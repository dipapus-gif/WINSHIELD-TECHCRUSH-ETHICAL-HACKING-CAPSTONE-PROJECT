Everything stays in your browser. Monitoring only runs while this page is open (background tabs are slowed by the browser). Suspending processes, quarantining programs, network isolation and Controlled Folder Access need the Windows app.

Protect a folder

Choose a folder and WinShield starts watching it right away. The browser asks for permission first and only this folder is visible to the page.

Safe self-test

Creates 60 harmless files in a WinShield-selftest folder inside a protected folder, then encrypts them with random data, renames them to .locked, drops a ransom-note file and touches a decoy. The real detection engine sees all of it. Nothing outside that folder is touched.

Emergency protection

Saves evidence, takes a recovery point of every file that has not been touched yet, and shows what to do next. It cannot stop the attacking program from a browser: disconnect the network and close or shut down the PC.
